### 📚 Description
En tant que développeurs web juniors, les étudiants doivent concevoir un site web relié à
une base de données comme par exemple un catalogue de produits organisé par
catégories ou mots-clés. Ce site doit présenter de manière lisible et ergonomique les
données stockées et permettre de naviguer au sein de celles-ci. Il doit permettre aux
utilisateurs d’ajouter des contenus par exemple en postant des commentaires ou en
réservant un produit. Les étudiants doivent répondre à la question : **Comment consulter
de manière fluide des contenus stockés dans une base de données et permettre aux
utilisateurs d’interagir avec ces contenus ?**
